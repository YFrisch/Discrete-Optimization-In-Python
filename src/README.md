# Source

This folder contains reusable educational implementations used across the notebooks:

- `polyhedra/fourier_motzkin.py` — projection by variable elimination
- `polyhedra/affine.py` — affine images of polyhedra
- `polyhedra/polar.py` — polar-cone conversions
- `polyhedra/representations.py` — small 2D H/V-representation conversions
- `polyhedra/integer_hull.py` — lattice-point enumeration and integer hulls in 2D
- `optimization/branch_and_bound.py` — a small LP-based branch-and-bound solver with a node trace
- `visualization/visualize_polyhedra.py` — 2D and 3D polyhedron visualization

The implementations prioritize readability and geometric intuition over production-scale performance.
